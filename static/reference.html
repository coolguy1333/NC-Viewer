How a line of G-code works

N40 G1 X50. Y20. F600 (cut to the corner)
  • Each line is one step. The machine reads the program from top to bottom, one line (a "block") at a time.
  • A line is made of words: a letter followed by a number. G1 says "move in a straight line at feed rate", X50. and Y20. say where to, F600 says how fast (600 mm/min).
  • Codes are "modal": they stay on until something changes them. After G1 F600, a line with just X10 is still a G1 at F600.
  • Comments in ( ) or after ; are notes for people. The machine ignores them.
  • Program zero (X0 Y0 Z0) is set on the machine with a work offset (G54). On a mill Z0 is usually the top of the part, so cutting moves have negative Z.
  • A typical program: set units and modes → pick a tool → start the spindle → move above the part → cut → retract → end with M30.
G90 G21 G17          (absolute, millimetres, XY plane)
T1 M6               (load tool 1)
S8000 M3           (spindle on, 8000 rpm)
G0 X0 Y0            (rapid above the start)
G43 Z25. H1        (tool length offset)
G0 Z2.
G1 Z-1. F200        (feed into the part)
G1 X50. F600       (cut)
G0 Z25.             (retract)
M5                 (spindle off)
M30                (end)
